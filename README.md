# Pondok Pesantren Daruttaubah

Website interaktif untuk Pondok Pesantren Daruttaubah - sebuah lembaga pendidikan Islam yang berdedikasi untuk mengembangkan karakter dan pengetahuan Islami bagi generasi muda.

## Fitur Utama

### 1. **Navigasi Responsif**
   - Menu navigasi yang mulus dan intuitif
   - Hamburger menu untuk perangkat mobile
   - Smooth scrolling ke berbagai bagian website

### 2. **Hero Section**
   - Desain yang menarik dengan latar belakang gradient
   - Call-to-action button untuk engagement
   - Animasi yang elegan saat page load

### 3. **Tentang Kami**
   - Informasi lengkap tentang Ponpes Daruttaubah
   - Fitur-fitur utama dalam bentuk list yang terstruktur
   - Layout yang responsif dengan gambar placeholder

### 4. **Program Pendidikan**
   - Program Tahfiz Qur'an
   - Ilmu Agama (Tafsir, Hadis, Fiqh, Akidah)
   - Pendidikan Formal (SD, SMP, SMA)
   - Ekstrakurikuler dan pengembangan bakat

### 5. **Tim Pengajar**
   - Profil guru dan pengajar berpengalaman
   - Informasi latar belakang dan keahlian
   - Design card yang menarik dengan avatar

### 6. **Statistik**
   - Menampilkan jumlah santri, guru, tahun berdiri, dan tingkat kelulusan
   - Animated counter untuk visualisasi yang menarik

### 7. **Form Kontak**
   - Form komunikasi dengan validasi sederhana
   - Informasi kontak lengkap (alamat, telepon, email, jam operasional)
   - Integrasi dengan social media

### 8. **Footer Komprehensif**
   - Links ke berbagai bagian website
   - Social media integration
   - Copyright dan informasi legal

## Cara Menggunakan

1. Clone repository ini
2. Buka file `index.html` di browser
3. Sesuaikan informasi dengan data Ponpes Daruttaubah yang sebenarnya
4. Tambahkan gambar ke direktori yang sesuai
5. Customisasi warna dan font sesuai kebutuhan

## Customization

### Mengubah Warna
Edit variabel CSS di bagian `:root` dalam `css/style.css`:

```css
:root {
    --primary-color: #1a5a3c;    /* Ubah warna hijau */
    --secondary-color: #2d8659;  /* Ubah warna hijau muda */
    --accent-color: #d4af37;     /* Ubah warna gold */
}
```

### Menambahkan Konten
- Edit informasi di section yang sesuai dalam `index.html`
- Tambahkan program, guru, atau fitur baru sesuai kebutuhan
- Update kontak dan informasi lokal

### Mengintegrasikan Backend
- Modifikasi `js/script.js` untuk mengirim form ke server
- Hubungkan dengan database untuk manajemen konten dinamis
- Integrasikan CMS jika diperlukan
